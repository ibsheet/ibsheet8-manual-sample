맞벌이 부부 가계부 - 사용자(남편/아내/공동)별 엑셀 다운로드

아래 시트의 데이터를 사용자별로 나눠 엑셀로 받는 4가지 방법입니다. 여러 파일은 사용자마다 파일 1개씩(총 3개), 워크시트는 한 파일 안에 사용자별 워크시트로 나눕니다.

  • 사용자별 여러 파일 : 사용자마다 임시 시트를 비동기로 만들어 각각 다운로드. 시트를 많이 만들어도 화면이 멈추지 않습니다.
  • 여러 파일 (directExcelData) : 임시 시트 없이 시트 하나에 데이터(JSON)만 바꿔가며 체이닝으로 다운로드. 그룹이 많을 때 가볍습니다.
  • 한 파일 워크시트 : 임시 시트 + 버퍼로 한 파일 안에 워크시트 3개.
  • 워크시트 (directExcelData) : 임시 시트 없이 버퍼로 한 파일에 워크시트 3개.
